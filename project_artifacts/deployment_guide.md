# Deployment Guide - Smart Financier

This guide covers deploying the Smart Financier application to **Render**, using **Supabase** as the PostgreSQL database provider. 

> [!IMPORTANT]
> The repository is already configured with `render.yaml` (Infrastructure as Code), `build.sh` (Deployment script), and `run.py` (WSGI entrypoint using Gunicorn). Deployment is primarily a matter of configuring your services and environment variables.

---

## Step 1: Provision the Database (Supabase)
Smart Financier relies on PostgreSQL for its relational database and Supabase Storage for profile photos.

1. **Create a Supabase Project**: Go to [Supabase](https://supabase.com/) and create a new project.
2. **Database URL**: Once provisioned, navigate to `Project Settings -> Database`. Locate the **Connection string** (URI). It will look like:
   `postgresql://postgres:[YOUR-PASSWORD]@db.xxxxxx.supabase.co:5432/postgres`
3. **Storage Bucket**: Navigate to `Storage` and create a public bucket named **`profile-photos`**.
4. **API Keys**: Navigate to `Project Settings -> API`. Copy the **Project URL** and the **anon `public` API key**.

---

## Step 2: Deploy the Application (Render)
We will deploy the Flask application as a Web Service on Render.

1. **Connect Repository**: Go to [Render](https://render.com/), create a new **Blueprint**, and connect your GitHub repository containing the Smart Financier code.
2. **Environment Configuration**: Render will automatically detect the `render.yaml` file and prompt you to supply values for the following environment variables:

| Variable | Description |
| :--- | :--- |
| `DATABASE_URL` | The PostgreSQL connection string from Supabase (Step 1.2). |
| `SUPABASE_URL` | The Project URL from Supabase (Step 1.4). |
| `SUPABASE_KEY` | The anon `public` API key from Supabase (Step 1.4). |

*(Note: The `SECRET_KEY` is automatically generated by Render, and `PYTHON_VERSION` is hardcoded to 3.10.0 in the yaml).*

3. **Deploy**: Approve the deployment. Render will execute `build.sh` which automatically:
   - Installs all dependencies via `pip install -r requirements.txt`.
   - Executes `flask db upgrade` to automatically run all Alembic migrations and create the database schema on your Supabase instance.
   - Starts the application using `gunicorn run:app`.

---

## Step 3: Initialization & First Login
Once the application is live:
1. Navigate to the Render URL (e.g., `https://smart-financier.onrender.com`).
2. Talisman will automatically ensure your traffic is routed over secure HTTPS.
3. Access the database directly (using `psql` or the Supabase dashboard) to manually insert your first `Super Admin` user into the `users` table, as there is currently no public registration form. 
   *(Ensure you generate the password hash using Werkzeug's `generate_password_hash` locally).*
